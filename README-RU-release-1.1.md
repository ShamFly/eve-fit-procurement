# EVE Fit Procurement release-1.1

> **Назначение.** EVE Fit Procurement помогает пилотам и логистам EVE Online преобразовывать корабельные фиты в понятные списки закупок. Утилита упрощает подготовку кораблей, переоснащение и дозакупку недостающего оборудования, позволяет контролировать процесс покупки и уменьшает количество ручных расчётов и ошибок.
>
> Предусмотрены три режима работы для одного, двух или трёх фитов: **«Объединение фитов»** складывает их содержимое для совместной закупки; **«Переоснащение»** формирует набор, достаточный для сборки любого из заполненных фитов, не дублируя общие предметы сверх необходимого количества; **«Дозакупка»** считает фит 1 имеющимся, а фиты 2 и 3 — целевыми и показывает общий минимальный набор недостающих предметов для перехода на любой из целей.
>
> При необходимости утилита может загрузить через **Fuzzwork** минимальные цены продажи в торговом хабе Jita. На их основе рассчитываются стоимость отдельных позиций и фитов, общая стоимость закупки и стоимость ещё не купленных предметов. Загрузка выполняется только по отдельной команде пользователя и требует подключения к интернету.
>
> Полный состав фитов, названия фитов и сохранённые состояния не передаются в интернет. Пока пользователь не запускает загрузку цен, утилита не выполняет исходящих сетевых запросов. При расчёте цен наружу передаются только названия или идентификаторы предметов, необходимые публичным API EVE ESI и Fuzzwork для поиска типов и цен.

## 1. История изменений

- **release-1.1**
  - Добавлено третье поле EFT-фита.
  - «Объединение фитов» и «Переоснащение» теперь учитывают все заполненные фиты.
  - В «Дозакупке» фит 1 считается имеющимся, а фиты 2 и 3 — альтернативными целями; выводится общий набор недостающих предметов, достаточный для любой цели.
  - При узком контейнере фиты переключаются внутренними вкладками; на широком экране все три поля показываются рядом.

## 2. Функции актуальной версии

- **Полностью локальный запуск.** Приложение состоит из одного HTML-файла и открывается непосредственно в современном браузере без серверного слоя и установки.
- **От одного до трёх EFT-фитов.** Текст можно вставлять вручную или кнопкой. Лишние пустые строки, табуляции и пробелы по краям очищаются автоматически.
- **Три режима расчёта.**
  - «Объединение фитов» складывает количества из всех заполненных фитов.
  - «Переоснащение» берёт максимальное количество каждой совпадающей позиции среди всех заполненных фитов.
  - «Дозакупка» считает фит 1 имеющимся, а фиты 2 и 3 — целевыми; выводится общая максимальная нехватка для переключения на любой целевой фит.
- **Множитель.** Количество результата можно увеличить для закупки нескольких одинаковых комплектов.
- **Настройки состава.** Можно включать или исключать корпуса и заряды, скрывать купленные позиции и включать группировку списка.
- **Группировка по назначению.** Предметы распределяются по корпусам, Low/Mid/High-слотам, ригам, подсистемам, дронам и файтерам, зарядам и скриптам, имплантам и бустерам, грузу и другим категориям.
- **Проверка данных.** Приложение сообщает о некорректном заголовке фита, неразобранных строках и предметах, которые не удалось найти через ESI.
- **Наглядное происхождение позиций.** Цветовые маркеры показывают предметы из фита 1, 2, 3 или нескольких фитов одновременно.
- **Контроль закупки.** Каждую позицию можно отметить купленной. Сводка показывает процент, количество купленных позиций и единиц, а после загрузки цен — купленную и общую стоимость.
- **Оценка Jita.** По кнопке загружаются минимальные цены продажи Jita по данным Fuzzwork. Показываются стоимость каждого предмета, полная стоимость фитов, общая стоимость списка и стоимость оставшихся покупок. Значения автоматически форматируются в тысячах, миллионах или миллиардах ISK.
- **Копирование.** «Копировать весь список» создаёт читаемый полный список в формате `Название xКоличество`. «Копировать остаток для Multibuy» исключает отмеченные позиции и использует формат `Название<TAB>Количество` для вставки в клиент EVE.
- **Поиск и фильтрация.** Итоговый список можно фильтровать по названию предмета.
- **Сохранение текущей работы.** Фиты, режим, множитель, настройки и отметки сохраняются в `localStorage` и восстанавливаются при следующем запуске.
- **Именованные состояния.** Состояние можно сохранить, открыть, обновить или удалить. Имя автоматически составляется из полных заголовков всех заполненных фитов в квадратных скобках и остаётся редактируемым.
- **Резервные копии.** Сохранённые состояния экспортируются в JSON и импортируются обратно.
- **Два языка.** Интерфейс полностью доступен на русском и английском; выбранный язык сохраняется.
- **Четыре темы.** Доступны цветовые темы Amarr, Caldari, Gallente и Minmatar; выбор сохраняется между запусками.
- **Адаптивная вёрстка.** На широком экране три поля фитов расположены рядом; при недостаточной ширине они переключаются внутренними вкладками. Интерфейс рассчитан на настольные компьютеры, MacBook Pro 14″ и мобильные экраны.
- **Приватность и сеть.** Тексты фитов и сохранённые состояния остаются в браузере. Сетевые запросы выполняются только при ручной загрузке цен: названия или идентификаторы предметов передаются публичным API EVE ESI и Fuzzwork.
